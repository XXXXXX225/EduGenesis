# 线性代数核心数学基石与多维向量算力

线性代数是整个机器学习和人工智能大模型体系的核心数学底座。所有的数据表示、变换与乘积操作，最终都可以归结为高维矩阵的乘法。

## 1. 向量 (Vector) 与矩阵 (Matrix)
* **多维向量**：在几何上代表高维空间中的一个点；在代数上是一个数字数组。例如一个 1024 维的 Embedding 向量表示一个词或者一句话的语义特征。
* **点积 (Dot Product)**：衡量两个向量的相似度。
  $$\mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^n u_i v_i$$
  如果点积接近于 1，说明两个特征高度对齐。

## 2. 矩阵乘法与线性空间变换
矩阵可以被看作是**空间的变换算子**。
* 当一个向量乘以一个矩阵时，实际上是将该向量从原空间投影、旋转或拉伸到了另一个空间中。
* 深度神经网络中，前向传播的每一层本质上都是一个权重矩阵 $\mathbf{W}$ 乘以上一层输出向量 $\mathbf{x}$ 并叠加偏置 $\mathbf{b}$：
  $$\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$$

## 3. 特征值 (Eigenvalue) 与特征向量 (Eigenvector)
满足关系：
$$\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$$
其中 $\mathbf{v}$ 是特征向量，$\lambda$ 是特征值。这在主成分分析（PCA）降维以及图像特征压缩中起到了决定性作用。
