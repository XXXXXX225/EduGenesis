# Python 内置核心数据结构

Python 内置了四种极度强大且高度优化的核心容器数据结构：列表、元组、字典和集合。

## 1. 列表 (List) 与 元组 (Tuple)
* **列表 (List)**：用中括号 `[]` 表示。**可变**的有序序列。支持任意位置插入、删除和修改。底层是动态数组，扩容时有一定开销。
* **元组 (Tuple)**：用小括号 `()` 表示。**不可变**的有序序列。一旦创建其内部引用不可更改。适合用于只读配置、函数多返回值传递，速度略快于列表。

## 2. 字典 (Dict) 与 集合 (Set)
* **字典 (Dict)**：用花括号 `{key: value}` 表示。键值对映射结构。**键必须是不可变且可哈希的对象**（如 `str`, `int`, `tuple`）。底层使用 Hash Table 实现，读取和查找时间复杂度为 O(1)。
* **集合 (Set)**：用花括号 `{value1, value2}` 表示。**无序、元素唯一**。常用于去重和数学上的交、并、差集运算。

## 3. 防御性编码：不可变性防御
在并发或复杂引用传递中，误修改全局或共享状态会导致不可预测的副作用。使用 `tuple` 代替 `list` 作为常量配置，或使用深拷贝 `copy.deepcopy()` 可以防止引用泄露导致的 Bug。
