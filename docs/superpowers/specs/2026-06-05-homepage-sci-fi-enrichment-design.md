# 首页极致科技感视觉与深度互动设计文档 (2026-06-05)

本设计文档详细规划了 **EduGenesis** 首页门户的第二次视觉与交互升级方案（方案 A）。本方案旨在通过引入 Canvas 粒子背景、3D 卡片倾斜特效、可交互的智能体代码修复沙盒、以及可联动的 6 维认知雷达，全面提升平台的科技震撼感与学术专业度。

---

## 一、 设计目标 (Goals)

1. **极致视觉特效**：
   - 全屏 Canvas 粒子流背景，支持鼠标排斥交互，营造科幻星空质感。
   - 所有核心卡片支持 3D 悬浮倾斜（3D Tilt）与反射流光镜面高亮（Glassmorphic Specular Highlight）。
2. **首页直达体验沙盒 (Mini Sandbox Playground)**：
   - 在首页提供直观的代码除零隐患修复演示。
   - 点击后展示主管、安全、画像、路径、沙盒等 5 个系统角色的流式打字对话与共识形成过程，最后自动用打字动画重构左侧的代码。
3. **自适应能力参数联动 (Cognitive Radar Customizer)**：
   - 提供 3 个自适应能力调节滑块。
   - 联动展示 6 维认知雷达图（动态 SVG 多边形插值变化）。
   - 伴随会签诊断文案卡片实时切换，揭示系统自适应重构学习路径的核心逻辑。

---

## 二、 详细设计说明 (Proposed Components)

### 1. Canvas 粒子流背景 & 3D Card Tilt
*   **Canvas Particle Background**:
    *   在 HTML 最底层固定定位放置一个 `<canvas id="space-particles-canvas">`。
    *   渲染 60-80 个粒子，它们随机漂移并在临近粒子间绘制纤细连线。
    *   监听鼠标位置，若鼠标靠近粒子（120px 内），粒子会被平滑推开，移开后缓动回位。
    *   在组件卸载或 `document.hidden` 时自动取消 `requestAnimationFrame` 以防 CPU 资源浪费。
*   **3D Card Tilt**:
    *   监听卡片上的 `mousemove` 事件。
    *   根据鼠标在卡片内的 X/Y 轴位置百分比，计算三维旋转角度 `rotateX` 与 `rotateY`（限制在 ±10deg 内）。
    *   使用 GSAP 的弹性缓动驱动卡片的 `transform: perspective(1000px) rotateX(...) rotateY(...) scale(1.02)`。
    *   动态更新卡片上方绝对定位的 `card-shine-overlay` 渐变中心点坐标。

### 2. 首页试玩沙盒 (Mini Sandbox Playground)
*   **布局结构**:
    *   放置于首页 Timeline 与 Topology Simulator 中间。
    *   左侧为 IDE 代码编辑器，使用暗色极客代码背景，高亮显示 Python 零除漏洞函数。
    *   右侧为系统日志监控台，上方有“⚡ 启动协同诊断与执行”按钮与进度条，下方为日志输出容器。
*   **交互时序**:
    1. 用户点击“启动协同诊断与执行”按钮。
    2. 控制台清空，共识进度条亮起，开始打字流式输出智能体协同日志（每次输出间隔约 600-800ms）。
    3. 在 2.4 秒后，左侧的 Python 代码利用 GSAP 或 React 打字状态触发自动重构修改，添加安全防御分支 `if not scores: return 0.0`。
    4. 执行到 3.2 秒时，沙盒显示测试用例通过日志，进度条瞬间充满，沙盒组件上方触发彩色粒子特效。

### 3. 自适应学术雷达控制面板 (Radar Customizer)
*   **布局与联动**:
    *   提供三个滑块：`编程实践深度`、`概念理解跨度`、`安全与边界意识`。
    *   右侧使用 `<svg>` 绘制一个 6 维正六边形雷达。其顶点坐标根据三个滑块的数值按比例缩放计算。
    *   三个滑块会改变状态变量，触发 React 重新计算 SVG `<polygon>` 的 `points` 属性。
    *   在路径智能体推荐卡片中，展示会签推荐文案。当滑块在阈值边界移动时，使用文字淡入淡出动画过渡，实时切换显示系统应对不同能力阶段的个性化教学方案。

## 三、 提议的变更文件

### 1. `frontend/src/index.css`
*   增加 Canvas 背景相关样式。
*   增加卡片 3D hover 的 `.tilt-card`，反射流光层 `.card-shine-overlay` 的镜面效果。
*   添加试玩沙盒、雷达滑块、以及雷达 SVG 科技填充的 CSS 样式。

### 2. `frontend/src/App.jsx`
*   在 `App` 组件内部挂载 Canvas 渲染 `useEffect`，并在卸载时进行销毁。
*   编写通用 3D Tilt 和光影追随的 React 鼠标事件函数。
*   添加试玩沙盒组件和雷达调试组件 of JSX 及对应的交互状态（打字定时器、进度条填充状态、滑块联动状态等）。
*   利用 GSAP 注册相应的动画，并在组件注销时进行 revert 清理。

## 四、 验证计划

1. **构建正确性**:
   - 运行 `npm run build` 验证 Vite 编译打包状态。
2. **运行流畅度**:
   - 在开启 Canvas 背景和 3D 卡片效果下，验证页面滚动及动画无明显掉帧（稳定 60FPS）。
3. **卸载安全性**:
   - 多次在“门户首页”与“系统后台”间切换，利用 Chrome 内存面板监控，确保 Canvas 定时器及动画帧在页面切走时完全销毁，无内存泄漏。
